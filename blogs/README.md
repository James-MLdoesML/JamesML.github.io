Keep each post’s content, source files, images, and downloads inside its post folder. Shared site styles, scripts, and the favicon live in `../assets/`.

On the hosted site, posts use clean URLs such as `/blogs/learning-dynamics/`. Local `file://` previews add `index.html` automatically. Legacy `.html` redirects inside this folder are retained; old root-level blog redirects have been removed.
